# World Flag Explorer

A kid-friendly app for exploring the world's flags. Search for a country by typing or speaking its name to see its flag, capital, population, languages, money, neighbors, and a fun fact. Then test yourself in four quiz modes: guess the country, find the flag, capital cities, and which country has more people.

Live site: https://imsovanara-web.github.io/Geography/

Country details and flag images come from the open [world-countries](https://github.com/mledoze/countries) dataset (ODbL license). Population figures are rounded estimates from the mid-2020s.
